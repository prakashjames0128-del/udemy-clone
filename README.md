# Udemy Clone Website

## 📖 About the Project

This is a simple **Udemy Clone** website that I built using **HTML5** and **CSS3**. The project is a front-end clone of the Udemy homepage, created to practice web development fundamentals such as page layout, styling, and responsive design.

As a recent graduate and beginner in web development, I created this project to improve my HTML and CSS skills and gain hands-on experience building real-world website layouts.

## 🚀 Features

* Clean and simple user interface
* Course cards section
* Navigation bar
* Categories section
* Responsive layout using CSS
* Modern design inspired by Udemy

## 🛠️ Technologies Used

* HTML5
* CSS3

## 📚 What I Learned

* Creating structured web pages with HTML
* Styling websites using CSS
* Using Flexbox for layouts
* Improving UI design skills
* Building a responsive web page

## 🎯 Future Improvements

* Add JavaScript for interactivity
* Improve responsiveness for all screen sizes
* Create multiple pages
* Add search functionality
* Connect the project with a backend in the future
